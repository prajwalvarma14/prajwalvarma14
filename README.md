### 🔓 CROWN EXPLOIT: THE DADDYION CHRONICLES

When my college ERP (IonCUDOS) made checking attendance feel like doing income tax on Internet Explorer 6, I didn't complain. **I hacked the friction.**

<div align="center">
  <img src="https://raw.githubusercontent.com/prajwalvarma14/prajwalvarma14/main/assets/daddyion_blueprint.svg" width="100%" alt="DaddyIon Architecture" />
</div>

<br/>

* **The Problem:** 14 manual clicks, unresponsive login sessions, broken mobile layout, zero bunk calculations.
* **The Solution:** Reverse-engineered the entire authentication session lifecycle, hijacked raw HTML tables (`attendance_ci_response.html`, `consolidated_marks.js`), extracted the payloads with BeautifulSoup & regex, and wrapped everything inside an autonomous Android (Kotlin + WebView bridge) app styled in high-contrast Tokyo-Night glassmorphism.
* **The Result:** Instant attendance forecasting, proxy radar, and an app that students actually love using.
